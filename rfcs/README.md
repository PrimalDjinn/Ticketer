# RFCs

Design proposals for larger changes to Ticketer, written before the code. Each one explains the problem, the options
considered, the proposed design and its cost, and lists open questions. Discuss an RFC in its pull request; once it's
accepted, its status changes to **Accepted** and the work is tracked in issues.
